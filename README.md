# 🌦️ WeatherX

### A futuristic, interactive weather experience.

WeatherX is a modern weather application designed to make weather information **visual, interactive, and engaging**.

Search for a city or location and explore weather information through a futuristic interface featuring **glassmorphism, dynamic themes, smooth animations, and weather-based visual effects**.

> 🌤️ **WeatherX — Don't just check the weather. Experience it.**

---

## ✨ Features

* 🌍 Search weather for any city or location
* 🌡️ Temperature information
* 🌤️ Current weather conditions
* 🥵 Feels-like temperature
* 💧 Humidity
* 💨 Wind speed
* ☀️ UV Index
* 👁️ Visibility
* 🌞 Animated sun
* ☁️ Animated clouds
* 🌧️ Rain effects
* ❄️ Snow effects
* ⚡ Lightning effects
* 🎨 Dynamic weather-based themes
* 🪟 Modern glassmorphism interface
* 📱 Responsive design
* ⚡ Smooth animations and transitions
* ❌ Friendly error handling

---

## 🎨 Weather Experience

WeatherX changes its visual environment based on the current weather condition.

| Weather           | Experience                          |
| ----------------- | ----------------------------------- |
| ☀️ Sunny          | Glowing sun and warm atmosphere     |
| 🌤️ Partly Cloudy | Sun with moving clouds              |
| ☁️ Cloudy         | Floating clouds and soft lighting   |
| 🌧️ Rainy         | Animated rain and cool atmosphere   |
| ❄️ Snowy          | Floating snow particles             |
| ⛈️ Storm          | Dark atmosphere, rain and lightning |

## ⚙️ How It Works

1. Search for a city or location.
2. WeatherX retrieves the available weather information.
3. The weather data is displayed in the interface.
4. The UI adapts to the current weather condition.
5. Background effects and animations change dynamically.

## 🔒 Privacy & Security

WeatherX is designed with a privacy-focused approach.

* No account is required to use the application.
* No passwords or personal profiles are required.
* Location information is only used for weather-related functionality.
* No unnecessary personal information is requested.
* Users can choose what location information they provide.
